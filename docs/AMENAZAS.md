# Modelo de amenaza y límites

Adversario: puede aportar contenido a una colección secundaria experimental que el
recuperador presenta como contexto. Pretende imponer una cadena ajena a la respuesta.
No controla pregunta, sistema, código, modelo o archivos oficiales. No recibe acceso
a herramientas. Los escenarios alteran únicamente datos sintéticos independientes.

Los detectores por patrones fallan con instrucciones sutiles y pueden confundir
citas benignas con instrucciones activas. JSON y delimitadores ayudan a separar
contenido, pero no garantizan aislamiento semántico en un LLM. El modo A se reserva
a evaluación controlada. Se mantienen controles de evidencia/citas comunes a todos
los modos para permitir una comparación explícita del mecanismo experimental.

La procedencia institucional y una fecha reciente o antigua no certifican vigencia.
Las relaciones normativas disponibles son conocidas, no exhaustivas. No se infiere
derogación por antigüedad. RCU-0252-2021 se excluye como histórico sin efecto.
RCU-0127-2020 modifica un texto base ausente, RCU-0435-2017. RCU-0009-2026 afecta una
disposición específica, no sustituye el reglamento entero. RCU-0317-2026 y
RCU-0590-2023 tampoco están disponibles localmente; no se inventa contenido.

El JSONL piloto contiene 115 páginas OCR pendientes. Se muestran como recuperación
provisional y se excluyen de evidencia fiable del generador. No se alteran OCR ni
respuestas gold. Aun los textos nativos carecen de certificación actual: el modo de
vigencia se abstiene. El modo documental acepta esa limitación explícitamente y no
convierte un extracto en requisito actual. Las citas se comprueban solo por archivo
y página; se necesita cotejo humano con PDF y revisión de contenido/alcance legal.

No se consumen APIs pagadas, no se descargan modelos y no se exponen secretos.
La ejecución es local; fuentes y bases derivadas están ignoradas en Git. Los
resultados versionados contienen IDs, hashes y métricas, sin texto documental.
No existe verificación automática contra documentos remotos ni certificación
jurídica. La interfaz no representa un servicio oficial de la UNSA.
